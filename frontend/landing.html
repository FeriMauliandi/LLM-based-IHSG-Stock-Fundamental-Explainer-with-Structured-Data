METODOLOGI VALUASI

Bagaimana Harga Wajar Dihitung?

Alih-alih mengandalkan tebakan atau rumus tunggal, aplikasi ini memadukan 4 model penilaian kuantitatif klasik:

1. Graham Number Formula Value Classic
Fair Value = √(22.5 × EPS × BVPS)

Formula klasik Benjamin Graham yang mengasumsikan batas PER 15x dan PBV 1.5x (15 × 1.5 = 22.5). Sangat efektif untuk industri mapan beraset nyata.

2. PE Benchmark Model Earnings Multiple
Fair Value = EPS × Target PE Acuan

Menghitung harga saham jika pasar mengapresiasi laba per lembar (EPS) pada kelipatan PER wajar sesuai rata-rata industrinya.

3. ROE-Adjusted PBV Model Capital Efficiency
Fair Value = BVPS × (ROE / Cost of Equity) × Base PBV

Menilai apakah valuasi saham sepadan dengan kemampuannya menghasilkan laba dari ekuitas. Sangat tepat untuk bank dan lembaga finansial.

4. Earnings Power Value (EPV) Sustainable Earning
Fair Value = Normalized EPS / Cost of Equity

Model konservatif Columbia Business School yang mengabaikan spekulasi pertumbuhan masa depan, murni melihat kekuatan laba berkelanjutan saat ini.

Formula Konsensus: 60% Rata-rata Terbobot + 40% Nilai Median untuk mengeliminasi dampak angka ekstrem (*outlier*).

Pertanyaan yang Sering Diajukan

Apakah saya harus membuat akun atau bayar langganan?

Tidak sama sekali. Aplikasi ini gratis, bersifat mandiri, dan dapat langsung digunakan tanpa perlu login, memasukkan email, atau membayar biaya langganan.

Dari mana data keuangan saham diperoleh?

Data diambil otomatis melalui Yahoo Finance API untuk saham-saham yang tercatat di Bursa Efek Indonesia (kode berakhiran .JK).

Mengapa sektor perbankan dinilai secara khusus?

Secara akuntansi, tabungan dan deposito nasabah bank dicatat sebagai liabilitas (utang), sehingga rasio DER bank secara alami berkisar 5x–8x. FINSIGHT secara cerdas mematikan penalti DER pada bank dan mengevaluasi Return on Assets (ROA) serta efisiensi modalnya.

Apakah hasil analisis ini merupakan ajakan beli/jual saham?

Bukan. Aplikasi ini adalah sarana analisis kuantitatif independen untuk membantu riset mandiri Anda. Keputusan investasi akhir tetap berada di tangan masing-masing investor (DYOR).
